An AI-powered web application that reviews and analyzes code using Google’s Generative AI (Gemini). Built with React (Vite) for the frontend and Node.js (Express) for the backend.
- Features
  * Paste or upload source code for instant AI review.
  * Uses Gemini API for intelligent feedback.
  * Clean, modern UI with syntax highlighting.
- Tech Stack
  * Frontend: React + Vite
  * Backend: Node.js + Express
- AI API: Google Generative AI (Gemini)
- Styling: Framer Motion, PrismJS, Highlight.js
